# D2R Mobile：iOS 17 / A16 实验性适配

这是 [jhaizhou-ops/d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile) 的非官方 iOS 17 兼容分支，保留上游历史、署名和 MIT 许可证。目标是主线 M3 路线的 iOS 17 化，不是重新实现游戏，也不是暴雪或上游的官方 iOS 17 支持。

## 当前基线：1.0.17 / build 2026101705

本次提交将累计适配源码同步到本地 **1705** 游玩基线，而非切换到1706或叠加未经证明有效的实验补丁。

- 保留 iOS 17 的 Metal 3 逐编码器资源声明、泛光及系统 UI 快照保护、GPU Scheduled 后直接呈现路径。
- 保留省电档的30 FPS周期处理与呈现票号关联；不是插帧，也不是承诺系统每秒必定回调60次。
- **1705输入/UI轮询**：改用主线程60Hz `NSTimer`，取消额外的 `CADisplayLink` 刷新请求；渲染30/60模式不再决定该轮询频率。定时器并不是硬实时输入或触控延迟验收。
- **默认普通游玩**：旧诊断配置只有在 `diagnostics_build.txt` 与当前构建号匹配时才启用；不匹配则忽略，不删除配置、资源或存档。
- 加入逐线程CPU时间、呈现票号和可选通道计时工具；normal模式不额外启用逐帧/线程/通道采样。

**仍为实验版：30 FPS卡顿、输入延迟与发热没有宣称全部解决。** 1705有A16/iOS17.0人工游玩反馈，但不是全流程验收；其他机型、iOS17.x、长期功耗、物理触摸到屏幕延迟及所有场景均未认证。宿主/模拟/静态检查不能当成A16实机性能成绩，GPU命令耗时也不等于利用率或整机瓦数。

## 构建与内容边界

**本仓库不提供可玩的IPA、游戏程序/资源、游戏衍生表/美术/着色器、完整ASTC载荷、密钥、存档、私有日志或录屏。** 从自己合法取得的游戏文件在本地生成输入；不要向issue提交这些文件。
