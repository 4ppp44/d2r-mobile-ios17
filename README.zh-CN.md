# D2R Mobile：iOS 17 / A16 实验性适配

这是[jhaizhou-ops/d2r-mobile](https://github.com/jhaizhou-ops/d2r-mobile)的非官方仅源码适配，基于v1.0.17（9de307e），包含后续Mac反射复制修复1784563。保留上游历史、署名和MIT许可证；不是暴雪官方发行或上游的iOS17支持承诺。

兼容实现包含iOS17逐编码器资源声明、泛光/系统UI快照保护、GPU进入Scheduled后直接呈现，以及省电档60Hz显示服务/每两拍生成一张真实游戏帧，名义30FPS，不插帧。

**当前仍为实验版，不宣称完全无卡顿、低功耗或全流程稳定。** 私有测试构建1.0.17/build2026101601，在iPhone14ProMax/A16、iOS17.0有约一分钟实机日志。后段报告呈现间隔33.36ms，前段仍有最高约100ms的p99窗口；固定25ms掉帧阈值会误算正常30FPS。长期温耗、触控延迟、其他机型和系统版本未验收。公开源码已独立完成未签名设备SDK清理构建，使用标准PNG图标；不冒称与私有IPA字节相同，也不视为新增A16游戏/功耗验收。

**不提供IPA、游戏程序/资源、游戏衍生美术/着色器、ASTC包、密钥、存档、私有日志或录屏。** 必须从自己合法取得的游戏文件生成输入；不要在issue上传敏感或版权受限文件。
